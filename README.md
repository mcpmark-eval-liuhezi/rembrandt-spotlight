# rembrandt-spotlight

Draft content package for the "Dutch Masters" blog series: the Rembrandt van Rijn spotlight, due for the Friday edition.

- `rembrandt-timeline.md` — chronological timeline of Rembrandt's works in the Rijksmuseum collection (10 works, 1626–1665), with each entry verified against the museum's official collection records.

Facts sourced from the Rijksmuseum collection data; supporting field notes live in `rembrandt-spotlight-source-notes`.
